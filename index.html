开始本地播放

  1. 打开“片库”，点击“导入”，在系统“文件”中选择视频。
  2. 点击视频开始播放。也可通过 USB 文件共享，将文件放入 App 的文档目录，再回到片库下拉刷新。
  3. 轻点画面显示控制栏；双击播放或暂停；长按临时切换 3 倍速；横向滑动调整进度。
  4. 打开播放器右上角设置，选择倍速、音轨与视频中包含的字幕。在 App 设置中可调整字幕显示。

连接 Windows 共享文件夹

  1. 让电脑和 iPhone/iPad 连接同一个可互通的局域网。将 Windows 网络配置设为“专用网络”。
  2. 打开视频文件夹的“属性 → 共享 → 高级共享”，启用共享，并给使用的账号读取权限；“安全”选项卡也需允许读取。
  3. 在电脑运行 ipconfig，记下当前网卡的 IPv4 地址和文件夹共享名称。
  4. 在 App“局域网”中添加连接：填写主机地址、共享名称、用户名及密码，端口通常为 445。填写账号密码，不是 Windows 解锁 PIN。
  5. 允许系统的“局域网”访问请求，测试连接并保存，进入共享目录后点击视频。

连接 Mac 或 NAS

Mac：在“系统设置 → 通用 → 共享 → 文件共享”中启用 SMB，并授权账号读取目录。NAS：开启 SMB2/SMB3 文件服务，使用 NAS 地址、共享名称和具有读取权限的账号连接。

常见问题

发现不到电脑，或连接失败

可直接填写 IP 地址；自动发现不到设备不代表不能连接。确认电脑没有休眠，设备未连接隔离的访客 Wi-Fi，Windows 防火墙允许专用网络的“文件和打印机共享”，以及 iOS 设置已允许 App 访问局域网。

视频没有声音或字幕

检查播放器中的音轨、内嵌字幕选项和设备音量。App 只能选择视频文件实际包含的轨道。常见封装包括 MP4、MKV、MOV 和 AVI；能否播放还取决于视频编码和设备性能。不支持 DRM 加密片源。

离线观看、后台与设备同步

可将共享视频保存到设备。下载时请保持 App 在前台；切换到后台会暂停播放。iPhone 和 iPad 的片库不会自动同步。

删除数据

长按本地视频可删除文件；在设置中清除播放记录；在局域网页面移除连接会同时删除该连接保存的密码。移除连接不会删除电脑上的视频。

App 不提供影视内容。请播放你有权访问和使用的文件。开源组件及许可可在 App“设置 → 关于与隐私 → 开源组件与许可”中查看。
